V27.5.8 — Client Login Screen Authentication
- Client login is now a real authenticated UI state; the post-login workspace is inaccessible while logged out.
- Prevented scrolling/visual exposure of the authenticated Client workspace before login.
- Added centralized authentication guards to protected sections, catalog rendering, game selection, launch, refresh, and status polling.
- Login now explicitly establishes the authenticated Client state only after Server authentication succeeds.
- Logout clears the Client authentication state and returns to the isolated Login Screen.
- Refresh/reload starts in the logged-out state; the Client does not restore the previous customer session.
- Added browser-history/hash protection so navigation cannot be used to bypass the Login Screen.
- Updated active Client release marker to V27.5.8.

V27.5.6 — Top Bar + Client Face Live Preview
- Top-level Manager navigation is now icon-only in the top bar; labels remain available through tooltips and inside dropdown items.
- Moved the global search into the top actions area beside Settings/utility icons; removed the separate search row.
- Reserved a dedicated brand area so navigation/search/actions cannot overlap the store logo or store name.
- Removed Login/Home preview-switch buttons from Customize Client; the right-side Client Face is now a single continuous LIVE preview.
- Fixed live preview synchronization so persisted Server assets (logo, background, video, main image and section icons) are not overwritten by CSS refreshes.
- Live preview now updates stored media and style fields without requiring preview-mode buttons.
- Client asset save uses the global profile endpoint when available, preserving the default profile behavior.
