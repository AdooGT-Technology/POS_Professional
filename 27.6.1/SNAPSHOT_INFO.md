# 27.6.1 source snapshot

This directory preserves the project source for release 27.6.1. The repository root remains the canonical working tree. The snapshot contains the Client, Manager, Server, tests, documentation, tracked design references (excluding generated audit reports), and the Pro Max UI styles.

For safety and to avoid generated/local state, runtime SQLite databases, ignored local credential/configuration files, Git metadata, caches, and build outputs are not copied.
